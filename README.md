# codegen-ai

AI code generation, analysis, and debugging platform.

## Features

- Generate implementation ideas from plain-language prompts
- Analyze project structure and runtime issues
- Highlight refactoring opportunities
- Summarize code health and technical direction

## Run locally

```bash
node server.js
```

Then open:

```text
http://localhost:3000
```

## API endpoints

- `GET /api/health`
- `GET /api/summary`
- `GET /api/features`

## Project status

This repository includes a working starter app scaffold for an AI coding platform using the built-in Node.js HTTP server.
